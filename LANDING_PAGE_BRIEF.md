# Caprigo Landing Page Brief

This is the current public-facing positioning brief for Caprigo.

Primary product site: `caprigoai.com`

## Core message

Caprigo is a local-first agent workspace. Users set up the runtime once, then launch persistent agents that operate across chat, tools, local scripts, and orchestrated multi-agent flows.

## Key promise

The user handles setup. The agent handles operation.

## What Caprigo is

- local-first
- workspace-based
- persistent agents
- LLM plus tools plus scripts
- orchestrator/worker capable
- marketplace-connected through `vibes-coded.com`

## What Caprigo is not

- not just a browser chat shell
- not only a hosted wrapper
- not vague autonomy marketing without operational controls

## Suggested landing page sections

1. Hero
2. How it works
3. Why Caprigo is different
4. Marketplace and skills
5. Beta expectations

## Suggested hero copy

**Caprigo**  
Local-first agents that work inside your real workspace.

Set up the runtime once, connect your model, then launch agents that can use tools, run scripts, and coordinate work across your machine.

## CTA direction

- Primary CTA: `View beta setup`
- Secondary CTA: `Browse skills on vibes-coded.com`
- Footer/support direction: link docs and install guidance from `caprigoai.com`, route skill commerce to `vibes-coded.com`
